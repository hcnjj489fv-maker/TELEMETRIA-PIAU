# Telemetria da Frota · PIAU Service Soluções LTDA

Dashboard de telemetria das caminhonetes 401 (SGP8E24), 402 (ROR6E65) e 403 (SIL1J12): km rodados, viagens, velocidade, horários e municípios, com filtros cruzados no estilo Power BI.

**Link:** https://hcnjj489fv-maker.github.io/TELEMETRIA-PIAU/

## Como atualizar

1. No computador, coloque os PDFs do rastreador na pasta `TELEMETRIA\PDFs`.
2. Dê dois cliques em `ATUALIZAR DASHBOARD.bat`. Ele gera o arquivo novo em `TELEMETRIA\site\index.html`.
3. Aqui no GitHub, clique em **Adicionar arquivo > Carregar arquivos**, arraste o `index.html` novo e clique em **Confirmar alterações**.
4. Espere de 1 a 2 minutos e abra o link com Ctrl+F5.

O link não muda. Quem já tem o link vê a versão nova.
